Netlify CMS used the Discourse subforum on https://answers.netlify.com/ , which is not an option for Decap as we are not affiliated with Netlify anymore. We decided to officiate this service as our forum, as it provides all the features that we need. It’s also very handy to move from issues to discussions and vice versa.
