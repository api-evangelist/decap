We took over this project a month ago and although there were not many commits to the main repository, we have been working on the project under the hood. We want the first Decap release to be a drop-in replacement, and we want to make sure that it works. We figured that the only way to upgrade libraries and not make breaking changes is to make the tests pass without changing any conditions.
