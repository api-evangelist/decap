We are happy to announce that the first release of Decap CMS is now available. It is released under 3.0 to honor the 2 major versions of the Netlify CMS. Decap on NPM: https://www.npmjs.com/package/decap-cms Add to your site Via script tag in admin.html: script src = "https://unpkg.com/decap-cms@^3.0.0/dist/decap-cms.js" > script > or via NPM: npm install decap-cms-app Changes Decap 3.0 is very similar to Netlify CMS 2.10.192 (the last available version), and it’s fully backward compatible.
